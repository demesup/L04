# Bug Fixer

## Input
You will receive:
1. The original Python source file.
2. The bug report(s) generated by the `bug-finder` skill (`Line:`, `Problem:`, `Example:`, `Fix:`).

## Instructions
1. **Systematic Bug Review:** Read **every single bug report block** provided in the input. Do not stop after the first report.
2. **Fix Every Bug:** Locate the exact function and line for *each* report and apply the necessary fix so that every function matches its docstring, handles edge cases cleanly, and removes security vulnerabilities.
3. **Preserve Structure:** Preserve all function names, parameter signatures, imports, and docstrings.
4. **Strict Output Rules:**
   - Output **ONLY complete, valid Python code** for the entire fixed file.
   - Do **NOT** include markdown code fences (```python or ```), line numbers, explanations, or extra text.
