# Bug Fixer

## Input
You will receive:
1. The original Python source file.
2. The bug report(s) generated by the `bug-finder` skill (`Line:`, `Problem:`, `Example:`, `Fix:`).

## Instructions
1. Carefully read every bug report block and locate the exact function and line in the source code.
2. Fix every reported bug so that each function matches its docstring, handles edge cases cleanly, and removes security vulnerabilities (such as hardcoded secrets or SQL string interpolation).
3. Preserve all function names, parameter signatures, imports, and docstrings.
4. Do not introduce new bugs or alter unrelated working behavior.

## Strict Output Rules
- Output **ONLY complete, valid Python code** for the entire fixed file.
- Do **NOT** include markdown code fences (```python or ```), line numbers, explanations, or extra text.
